# Getting Started

This page provides basic information for Arrow+ on **legacy versions**.

::: warning You are viewing the **Legacy System** docs
This covers **1.21.11-NeoForge** and all older versions (1.21.10, 1.21.8, 1.20.1, 1.21.x-Forge, 1.21.x-Fabric, etc.).

In this system, **arrows** are datapack-driven, but **sticks and feathers** are individual registered items — not datapacks.

If you are on **26.3.0.2+**, see the [modular arrow docs](/getting-started). On **26.1 to 26.3.0.1** or **1.21.1-NeoForge**, see the [26.1 – 26.3.0.1 docs](/v26-1/getting-started). The **version switcher** in the top navigation moves between them.
:::

## Overview

In the legacy system, Arrow+ adds **18 new arrow types**. Arrows are defined via the `arrowplus/arrows/` datapack registry. However, **sticks and feathers** are separate individual registered items (e.g. `arrowplus:copper_stick`, `arrowplus:gilded_feather`) — they are **not** datapack entries.

## Recipe Viewers

Arrow+ has built-in JEI/REI integration on supported legacy versions to display arrow recipes.
