# Tipped Arrows

Any Arrow+ arrow can be tipped with a potion effect using a **Cauldron**, just like vanilla tipped arrows.

## How to Tip an Arrow

1. Fill a Cauldron with a lingering potion.
2. Right-click the Cauldron while holding Arrow+ arrows.
3. The arrows become tipped with the potion's effect.

## Name Format

Tipped Arrow+ arrows follow the naming format:

```
<Arrow Name> of <Effect Name>
```

For example, a Diamond Arrow tipped with Poison becomes **"Diamond Arrow of Poison"**.

## Behaviour

- Tipped arrows apply the potion effect on hit.
- The arrow's `baseDamage` still applies in full.
- On legacy versions, tipped arrows **are** compatible with the Infinity enchantment (unlike the new system where they are always excluded).
